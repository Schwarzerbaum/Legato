# ProductHunt Launch

**Name:** BlackSwanX

**Tagline:** 174 AI experts + 200 citizens predict the future adversarially. Runs on your laptop. Free.

**Description:**

BlackSwanX is an adversarial intelligence engine that finds where the crowd is wrong.

Enter any topic. 200 citizen agents react with biased, emotional opinions. A BlackSwan Assassin finds the kill shot nobody's talking about. A Cognitive Dissonance Matrix measures the gap between belief and reality.

The result isn't a report — it's a Decision-Ready Map with a Linchpin (the one thing everything depends on) and an Antifragile Play (how to profit regardless of which scenario wins).

**Key Features:**
• 174 domain expert agents (from Chaos Mathematician to Vedic Astrologer)
• 200 citizen agents with diverse personas
• BlackSwan Assassin finds low-probability high-impact threats
• Cognitive Dissonance Matrix: The Trap / The Blindspot / The Chaos
• SONA self-learning — gets smarter with every run
• Runs 100% locally on Ollama — zero API cost, zero cloud dependency
• Auto-detects your hardware and picks optimal models
