**Title:** Show HN: BlackSwanX – 174 AI agents + 200 citizens predict the future adversarially, runs on Ollama

**Body:**

BlackSwanX is an adversarial intelligence engine that runs entirely on local Ollama models. No API keys, no cloud, no cost.

Instead of asking "what will happen?", it asks "where is everyone wrong?"

The pipeline: crawl 5 free sources → compress 10K posts into 5 "Social Personas" → BlackSwan Assassin finds the Kill Shot (the threat nobody sees) → 200 citizen agents react with biased, emotional opinions → Cognitive Dissonance Matrix calculates where the crowd disagrees with reality → Decision-Ready Map with an Antifragile Play.

Three local models: llama3.2:3b (citizen swarm), phi4:14b (assassin reasoning), mistral-small:24b (synthesis). Runs on 16GB MacBook.

174 expert agents including a Chaos Mathematician (tipping points), a Vedic Astrologer (yes, really), and a Panic Seller that represents the retail emotion signal.

Self-learning via SONA — the system audits every agent after each run, boosts the ones that caught risks, demotes the ones that missed threats.
